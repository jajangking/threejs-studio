# Kontrak — jam dinding kuarsa (revisi mekanik)

Konsep: jam kuarsa dengan dial semi-transparan sehingga gear train, kumparan, rotor, kristal, dan baterai terbaca dari depan tanpa merusak siluet klasik.
Objek wajib: casing-jam, kaca/bezel, wajah-jam, penanda-jam, jarum-jam/menit/detik, baterai-aa, pcb-kuarsa, kristal-kuarsa, kumparan-motor, rotor-stepper, gir-detik/menit/jam-kuarsa, penutup belakang/braket gantung.
Palet: #f5ecdc dial, #c9a227/#b08d57/#d4af37 kuningan, #2a303a penopang, #1d6b46 PCB, #b87333 tembaga, #c0392b jarum detik.
Kamera: default [0,2.6,6] → [0,2.5,0], fov 45; tur 5 shot tetap dipertahankan.
Lighting: hemisphere + key hangat + fill biru, bloom 0.25/0.5/0.9.
Acceptance: smoke 8/8; arah jarum clockwise dari depan; mekanik terlihat jelas; controls berupa array slider, bukan objek type controls.
